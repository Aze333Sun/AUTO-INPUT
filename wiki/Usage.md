# 使用说明

## 输入法切换规则

插件根据当前光标所在场景自动切换输入法：

| 场景 | 自动切换为 | 说明 |
|------|-----------|------|
| 代码区域 | 英文 | 编写代码时自动使用英文输入法 |
| 注释区域 | 中文 | 编写注释时自动使用中文输入法 |
| 工具窗口 | 英文 | 在 Terminal、Build 等工具窗口中使用英文 |
| 离开 IDE | 中文 | 鼠标离开 IDE 主窗口时切换为中文 |

## IdeaVim 模式

当安装了 IdeaVim 插件时，AUTO-INPUT-CH-EN 会自动适配 Vim 操作模式：

| Vim 模式 | 输入法行为 |
|----------|-----------|
| Normal 模式 | 英文输入法 |
| Visual 模式 | 英文输入法 |
| Operator Pending 模式 | 英文输入法 |
| Insert 模式（代码中） | 英文输入法 |
| Insert 模式（注释中） | 中文输入法 |

### IdeaVim 工作原理

1. 插件通过 `Class.forName()` 检测 IdeaVim 是否安装
2. 如果安装，注册 `ModeChangeListener` 监听 Vim 模式变化
3. 在非 Insert 模式下，强制使用英文输入法
4. 在 Insert 模式下，根据光标位置判断是代码还是注释，自动切换

## 使用场景详解

### 场景 1：编写代码

```
// 光标在此处 → 英文输入法
public void hello() {
    // 光标在此处 → 中文输入法
    String message = "你好世界";
}
```

### 场景 2：编写注释

```java
/**
 * 这是一个方法  ← 光标在注释中 → 中文输入法
 * @param name 参数名  ← 中文输入法
 */
public void method(String name) {
    // 这是单行注释  ← 中文输入法
    int x = 1;  // 这是行尾注释  ← 中文输入法
}
```

### 场景 3：使用 IdeaVim

```java
// Normal 模式下移动光标 → 英文输入法
// 按 i 进入 Insert 模式 → 根据光标位置自动切换
// 按 Esc 返回 Normal 模式 → 英文输入法
```

### 场景 4：切换编辑器

1. 在文件 A 的注释中（中文输入法）
2. 切换到文件 B 的代码中
3. 插件自动切换到英文输入法

### 场景 5：离开 IDE

1. 在 IDE 中编辑代码（英文输入法）
2. 鼠标点击 IDE 外的窗口
3. 插件切换到中文输入法
4. 返回 IDE 时，恢复之前的输入法状态

## 使用技巧

### 提高效率

1. **首次使用：** 安装后重启 IDE，然后手动切换一次输入法，让插件校准初始状态
2. **离开 IDE 后返回：** 插件会自动切换到你上次离开时的输入法状态
3. **切换编辑器标签页：** 插件会根据新光标位置自动调整输入法

### 注意事项

1. **防抖机制：** 插件有 100ms 的防抖间隔，快速移动光标时可能不会立即切换
2. **工具窗口：** Terminal、Build 等工具窗口默认使用英文输入法
3. **字符串字面量：** 字符串中的中文不会触发切换（因为光标在代码区域）

## 支持的编程语言

插件通过 IntelliJ PSI API 检测注释，因此只要 IDE 能解析该语言的语法，插件就能正确识别注释区域。

支持的语言包括：
- Java, Kotlin
- Python
- JavaScript, TypeScript
- C, C++
- Go
- Rust
- Ruby
- PHP
- Swift
- Scala
- Perl
- Lua
- SQL
- CSS, HTML, XML
- YAML, Shell

## 输入法兼容性

| 输入法 | 支持状态 | 说明 |
|--------|---------|------|
| 微软拼音 | ✅ | 完全支持 |
| 搜狗输入法 | ✅ | 完全支持 |
| 百度输入法 | ✅ | 完全支持 |
| 微信输入法 | ❌ | 不支持 |

> **原理：** 插件通过 Windows IME API（`imm32.dll`）查询输入法状态。微信输入法不兼容标准 IME 接口，因此无法检测。
